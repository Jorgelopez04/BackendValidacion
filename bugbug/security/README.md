# Pruebas de Seguridad con BugBug

En esta carpeta puedes agregar tus pruebas de seguridad automatizadas usando BugBug.

## ¿Qué es una prueba de seguridad?
Son pruebas que buscan vulnerabilidades comunes, como inyecciones o accesos indebidos.

## Ejemplo de archivo de prueba
Consulta el archivo `example-security.json` para ver cómo estructurar una prueba.

## ¿Cómo ejecutar una prueba?
1. Sube tu prueba a BugBug (web o CLI).
2. Ejecuta la prueba con:
   ```sh
   bugbug run <test-id> --api-key <your-api-key>
   ```

Más información en la [documentación oficial](https://bugbug.io/docs/cli/).
