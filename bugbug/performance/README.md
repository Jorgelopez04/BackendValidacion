# Pruebas de Performance con BugBug

En esta carpeta puedes agregar tus pruebas de performance automatizadas usando BugBug.

## ¿Qué es una prueba de performance?
Evalúan el tiempo de carga, respuesta y estabilidad bajo carga de tu aplicación.

## Ejemplo de archivo de prueba
Consulta el archivo `example-performance.json` para ver cómo estructurar una prueba.

## ¿Cómo ejecutar una prueba?
1. Sube tu prueba a BugBug (web o CLI).
2. Ejecuta la prueba con:
   ```sh
   bugbug run <test-id> --api-key <your-api-key>
   ```

Más información en la [documentación oficial](https://bugbug.io/docs/cli/).
